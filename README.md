# Java Mines Game

A Java console-based game project demonstrating object-oriented design and separation of concerns using model, view and controller packages.

## Highlights
- Object-oriented domain modelling for players, mines, gems and positions
- Controller-based game flow and event handling
- Text-based user interface
- Modular package structure separating model, view and controller responsibilities

## Technologies
Java, OOP, MVC-style architecture
